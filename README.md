# TenderFlow

MVP корпоративной тендерной площадки: заказчик публикует закупки и выбирает победителя, поставщики находят тендеры и подают предложения.

## Функциональность

**Поставщик**

- регистрация компании, восстановление пароля и заявка на аккредитацию;
- каталог закупок с поиском, фильтрами и избранным;
- участие в закрытых конкурсах и открытых аукционах;
- подача и обновление предложения до дедлайна;
- вопросы заказчику, история участия и уведомления.

**Заказчик**

- черновики и публикация закупок;
- выбор закрытого конкурса или открытого аукциона;
- несколько лотов, технические документы и требования;
- аккредитация и реестр поставщиков;
- ответы на вопросы, сравнение заявок и выбор победителя;
- аналитический кабинет с бюджетами и показателями.

**Платформа**

- организации и роли сотрудников, готовые к будущему SaaS-режиму;
- закрытие просроченных процедур фоновой задачей;
- аудит ключевых действий и центр уведомлений;
- MinIO для документов и PostgreSQL для бизнес-данных;
- адаптивный интерфейс и административная панель Django.

## Запуск в Docker

```bash
cp .env.example .env
docker compose up --build -d
docker compose exec web python manage.py seed_demo
```

Сайт: http://localhost:8000  
Админка: http://localhost:8000/admin/

Демо-пользователи:

| Роль | Логин | Пароль |
|---|---|---|
| Заказчик | `customer` | `demo12345` |
| Поставщик | `supplier` | `demo12345` |
| Поставщик | `partner` | `demo12345` |

Для создания администратора:

```bash
docker compose exec web python manage.py createsuperuser
```

## Архитектура и развитие

Текущий стек: Django 5, PostgreSQL 17, Redis, Celery, MinIO, Nginx, Gunicorn, HTMX и Docker Compose.

Compose поднимает веб-приложение, БД, очередь фоновых задач, планировщик, объектное хранилище документов и reverse proxy. MinIO Console доступна на http://localhost:9001.

```text
nginx -> web (Django/Gunicorn) -> PostgreSQL
                    |          -> MinIO
                    +-> Redis <- Celery worker / beat
```

Перед промышленным запуском нужно вынести секреты в защищенное окружение, подключить HTTPS, объектное хранилище для документов, аудит действий, уведомления и резервное копирование PostgreSQL. Следующими модулями целесообразно добавить многолотовые закупки, файлы ТЗ, протоколы, вопросы поставщиков и этапы согласования.
