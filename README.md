# WB Tender

Рабочая корпоративная тендерная площадка Wildberries: сотрудники проводят закупки и согласования, поставщики проходят аккредитацию и подают предложения.

## Функциональность

**Поставщик**

- регистрация компании, восстановление пароля и заявка на аккредитацию;
- каталог закупок с поиском, фильтрами и избранным;
- участие в закрытых конкурсах и открытых аукционах;
- подача и обновление предложения до дедлайна;
- вопросы заказчику, история участия и уведомления.

**Заказчик**

- черновики и публикация закупок;
- выбор закрытого конкурса или открытого аукциона;
- несколько лотов, технические документы и требования;
- внутреннее согласование закупок по ролям владелец/менеджер/эксперт;
- аккредитация и реестр поставщиков;
- ответы на вопросы, сравнение заявок и выбор победителя;
- аналитический кабинет с бюджетами и показателями.
- протоколы результатов, договорный реестр и CSV-экспорт.

**Платформа**

- организации и роли сотрудников, готовые к будущему SaaS-режиму;
- закрытие просроченных процедур фоновой задачей;
- аудит ключевых действий и центр уведомлений;
- MinIO для документов и PostgreSQL для бизнес-данных;
- адаптивный интерфейс и административная панель Django.
- почасовая синхронизация тендеров из внешних JSON API без создания дублей.

## Запуск в Docker

```bash
cp .env.example .env
docker compose up --build -d
docker compose exec web python manage.py seed_demo
```

Сайт: http://localhost:8000  
Админка: http://localhost:8000/admin/

Демо-пользователи:

| Роль | Логин | Пароль |
|---|---|---|
| Заказчик | `customer` | `demo12345` |
| Поставщик | `supplier` | `demo12345` |
| Поставщик | `partner` | `demo12345` |

Для создания администратора:

```bash
docker compose exec web python manage.py createsuperuser
```

## Архитектура и развитие

Текущий стек: Django 5, PostgreSQL 17, Redis, Celery, MinIO, Nginx, Gunicorn и Docker Compose.

Compose поднимает веб-приложение, БД, очередь фоновых задач, планировщик, объектное хранилище документов и reverse proxy. MinIO Console доступна на http://localhost:9001.
Сервис `backup` ежедневно создает архив PostgreSQL и хранит резервные копии 7 дней.

Проверка восстановления внутри контейнера PostgreSQL:

```bash
docker compose run --rm --entrypoint sh backup /scripts/restore_backup.sh /backups/<backup>.dump
```

```text
nginx -> web (Django/Gunicorn) -> PostgreSQL
                    |          -> MinIO
                    +-> Redis <- Celery worker / beat
```

Для промышленного окружения установите `DJANGO_DEBUG=0`, уникальный `DJANGO_SECRET_KEY`, HTTPS-параметры cookies и `SECURE_SSL_REDIRECT=1`. Резервные копии необходимо дополнительно выгружать во внешнее защищенное хранилище и регулярно проверять восстановление.

Production-шаблон переменных находится в `.env.production.example`. TLS должен завершаться на внешнем ingress/load balancer либо на отдельном HTTPS-конфиге Nginx.

## Импорт тендеров из внешнего сайта

В админке откройте `Источники импорта тендеров` и создайте источник. Укажите JSON API,
заказчика, владельца импортированных тендеров и при необходимости путь к списку,
например `result.items`.

По умолчанию ожидаются поля:

```json
{
  "id": "external-42",
  "number": "EXT-42",
  "title": "Поставка оборудования",
  "category": "goods",
  "description": "Описание",
  "requirements": "Требования",
  "delivery_address": "Москва",
  "budget": "150000.00",
  "deadline": "2026-06-30T18:00:00+03:00",
  "procedure": "auction",
  "auction_step": "5000",
  "status": "active",
  "url": "https://source.example/tenders/42"
}
```

Для API с другими именами заполните `Соответствие полей`, например:

```json
{"external_id": "uid", "title": "name", "deadline": "dates.finish"}
```

Значения секретного заголовка не хранятся в базе. Укажите имя заголовка и название
переменной окружения, затем добавьте токен в `.env`, например
`EXTERNAL_TENDER_API_TOKEN=Bearer ...`.

Celery Beat запускает синхронизацию раз в час. Ручная проверка:

```bash
docker compose exec web python manage.py sync_external_tenders
```

Если внешний сайт не предоставляет JSON API, добавьте отдельный адаптер получения
данных в `procurement/imports.py`; бизнес-логика обновления останется без изменений.
